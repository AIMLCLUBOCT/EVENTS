## Overview

The **EVENTS** repository serves as the official, historical archive of all technical events and student gatherings conducted by AIML Club OCT. 

For every event, we maintain an archived record with:
- Speaker & Organizer profiles.
- Session agenda and keynote slides.
- Code repositories and demo resources.
- Curated photographs and media recordings.
- Summary outcomes, participation highlights, and key takeaways.

## 📋 Standard Event Directory Structure

Every archived event in this repository follows a clean, standardized folder layout:

```text
EVENTS/[year]/[event-slug]/
├── README.md              # Complete event overview, agenda, speakers, and outcomes
├── poster/                # High-res official event poster
├── presentation/          # Keynote slide decks (PDF format preferred)
├── resources/             # Links to demo code, datasets, or notebooks
└── photos/                # Curated event photographs (no private data)
```

---

## 🔒 Privacy & Safety Guidelines

To protect member privacy, never upload or commit:
- Unredacted attendance sheets with student phone numbers, email addresses, or roll numbers.
- Unofficial private conversations or scorecards.
- Personal identification documents or ID badges.
