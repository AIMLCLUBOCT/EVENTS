## 📝 Session Summary
This session was designed as a zero-to-one entry point for students stepping into Artificial Intelligence and Machine Learning. The session demystified core terminology, differentiated classical rule-based programming from learning from data, and demonstrated live supervised learning workflows.

---

## 🧠 Core Topics Covered
1. **What is Machine Learning?** How data patterns replace hardcoded heuristics.
2. **The 3 Paradigms:** Supervised Learning, Unsupervised Learning, and Reinforcement Learning.
3. **The ML Pipeline:** Data collection $\to$ Cleaning $\to$ Feature Extraction $\to$ Training $\to$ Evaluation.
4. **Environment Setup:** Getting started with Python 3.10+, VS Code, and virtual environments.
5. **Community Roadmaps:** Introduction to the [AIML Club OCT Learning Resources](../../../learning_resources/).
